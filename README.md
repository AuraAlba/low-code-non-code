# Demostración Práctica Low-Code / No-Code: Appsmith & n8n

Este repositorio contiene la guía técnica, instrucciones de configuración y materiales prácticos para la sesión en vivo y el taller de la asignatura.

## Contenido del Repositorio

* [📁 Appsmith](./appsmith/README.md): Guía de construcción del panel frontend, motor de reglas modular en JS (`EvaluadorEngine`) e integración con API externa de prueba.
* [📁 n8n](./n8n/README.md): Configuración del flujo de trabajo guiado por eventos, recepción vía Webhook, evaluación de severidad y notificaciones.
* [📁 Taller](./taller/README.md): Ejercicio práctico para los estudiantes enfocado en la orquestación de alertas e incidentes de TI.
